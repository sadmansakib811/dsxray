X-ray a .DS_Store file

macOS Finder leaves a hidden .DS_Store in every folder it opens. It stores icon positions, window sizes and comments, keyed by file name. Upload one with a website or commit it to a repository, and anyone can read which files sit in that folder. See exactly what yours gives away.

Drop a .DS_Store file here

It's read right here by a Rust program compiled to WebAssembly. Nothing is uploaded. In Finder, ⌘⇧. shows hidden files.

        What is this?
        
    
        dsxray parses Apple's undocumented .DS_Store format: a small buddy allocator that
      holds a B-tree of records. The parser is written in Rust, never trusts a length or pointer in the file, and was
      checked record by record against an independent implementation on real Finder files.
      The same code runs as a command-line tool: dsxray scan ./site fails a deploy when a
      .DS_Store would go out with it.
